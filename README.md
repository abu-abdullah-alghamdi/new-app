# عيادتي — تطبيق Flutter

تطبيق حجز مواعيد عربي (RTL) بخط IBM Plex Sans Arabic: الدخول برقم الجوال ورمز من 4 أرقام، ثم المعلومات الشخصية، الرئيسية، الأطباء، الخدمات والسلة والدفع، مواعيدي، وحسابي، مع الشريط الزجاجي العائم وانتقالات iOS الأصلية (والسحب من الحافة للرجوع).

> رمز الدخول للتجربة: **1111**

## المتطلبات (مرة وحدة على الماك)

1. **Xcode** من App Store، ثم افتحه مرة ووافق على الشروط.
2. **Flutter**: من flutter.dev (أو `brew install --cask flutter`).
3. **CocoaPods**: `brew install cocoapods`
4. تأكد إن كل شي جاهز: `flutter doctor`

## التشغيل على Xcode

من داخل مجلد المشروع:

```bash
chmod +x scripts/dev.sh
./scripts/dev.sh run
```

السكربت يجهز مشروع iOS أول مرة، ويحمّل الحزم، ويفتح Xcode، ويشغّل التطبيق على المحاكي.
إذا طلب Xcode تختار جهاز، اختر أي iPhone من القائمة اللي فوق مرة وحدة.

## سحب التحديثات وإعادة التشغيل

```bash
./scripts/dev.sh update    # يسحب آخر نسخة من GitHub ويعيد البناء والتشغيل في Xcode
./scripts/dev.sh watch     # يراقب GitHub كل 30 ثانية، وأي تحديث جديد يسحبه ويشغّله تلقائياً
```

وللتطوير السريع من الطرفية مع Hot Reload: `./scripts/dev.sh sim`

## ربط المشروع بـ GitHub (مرة وحدة)

التحديث التلقائي يحتاج مستودع على GitHub:

```bash
# أنشئ مستودع فاضي على github.com باسم areem_clinics ثم:
git remote add origin https://github.com/<اسمك>/areem_clinics.git
git push -u origin main
```

بعدها أي تحديث ينرفع على هذا المستودع، أمر `update` أو `watch` يسحبه ويشغّله.

## هيكل الملفات

```

  theme.dart           الألوان

  services_data.dart   الخدمات والفروع والأسعار

  payments.dart        بوابة الدفع (حالياً شكلية)

  screens/             كل الشاشات

```

## إمكانية الوصول ومعايير آبل

- الوضع الداكن يتبع إعداد الجهاز تلقائياً.
- "تقليل الحركة": الانتقالات تصير تلاشي بسيط، وتتوقف الحركات الثانية.
- "زيادة التباين": الشريط العائم يصير معتم بحد واضح بدل الزجاج، والبطاقات تاخذ حدود.
- تكبير الخط: النص والأزرار يكبرون، والكبسولات والشريط لهم حد أقصى عشان ما يتكسرون.
- قارئ الشاشة يعرف اليوم والوقت المختار، والأيام المغلقة، والأوقات المحجوزة.
- حذف الحساب من صفحة "حسابي" (شرط من آبل لأي تطبيق فيه تسجيل دخول).

## قبل النشر الفعلي

- رقم العيادة في `lib/data.dart` (المتغير `clinicPhone`) قيمة تجريبية، غيّره لرقم العيادة.
- نص سياسة الخصوصية في `lib/screens/privacy_screen.dart` تجريبي، استبدله بالنص المعتمد.

- الرمز حالياً ثابت (1111). في النسخة الحقيقية يُرسل برسالة SMS عن طريق مزوّد رسائل، ويكون عشوائي.
- البيانات (الأطباء، الخدمات، الفروع، المواعيد، الطلبات، الحسابات) محفوظة داخل التطبيق للعرض فقط، وتحتاج ربط بخادم.
- أرقام الأطباء (المرضى، التقييم، التقييمات) وتقييمات الخدمات وتعليقات المستخدمين ونبذات الخدمات (`serviceReviews` و `serviceAbout` في `lib/services_data.dart`) تجريبية: استبدلها بالحقيقية، آبل ما تقبل تقييمات وهمية.
- **الدفع شكلي**: لازم يتربط ببوابة دفع حقيقية قبل الرفع على App Store (آبل ترفض الدفع الوهمي).
  اكتب كلاس يطبّق `PaymentGateway` في `lib/payments.dart` وغيّر `PaymentGateway.instance` له، وباقي التطبيق ما يتغير.
  زر Apple Pay الحقيقي لازم يكون زر آبل الرسمي (مثلاً عن طريق حزمة `pay`).
- صور الخدمات حالياً أيقونات: استبدلها بصور حقيقية في `lib/services_data.dart`.
- نص "الشروط والأحكام" في `lib/screens/terms_screen.dart` تجريبي.
- لتشغيله على آيفون حقيقي: افتح `ios/Runner.xcworkspace` في Xcode، ومن Signing & Capabilities اختر حسابك (Team).
