# عيادات أريام — تطبيق Flutter

تطبيق حجز مواعيد عربي (RTL) بخط IBM Plex Sans Arabic، بنفس تصميم النموذج: الدخول برقم الجوال ورمز من ٤ أرقام، الرئيسية، الأطباء، الحجز، التأكيد، مواعيدي، وحسابي، مع الشريط الزجاجي العائم وانتقالات iOS الأصلية (والسحب من الحافة للرجوع).

> رمز الدخول للتجربة: **1111**

## المتطلبات (مرة وحدة على الماك)

1. **Xcode** من App Store، ثم افتحه مرة ووافق على الشروط.
2. **Flutter**: من flutter.dev (أو `brew install --cask flutter`).
3. **CocoaPods**: `brew install cocoapods`
4. تأكد إن كل شي جاهز: `flutter doctor`

## التشغيل على Xcode

من داخل مجلد المشروع:

```bash
chmod +x scripts/dev.sh
./scripts/dev.sh run
```

السكربت يجهز مشروع iOS أول مرة، ويحمّل الحزم، ويفتح Xcode، ويشغّل التطبيق على المحاكي.
إذا طلب Xcode تختار جهاز، اختر أي iPhone من القائمة اللي فوق مرة وحدة.

## سحب التحديثات وإعادة التشغيل

```bash
./scripts/dev.sh update    # يسحب آخر نسخة من GitHub ويعيد البناء والتشغيل في Xcode
./scripts/dev.sh watch     # يراقب GitHub كل ٣٠ ثانية، وأي تحديث جديد يسحبه ويشغّله تلقائياً
```

وللتطوير السريع من الطرفية مع Hot Reload: `./scripts/dev.sh sim`

## ربط المشروع بـ GitHub (مرة وحدة)

التحديث التلقائي يحتاج مستودع على GitHub:

```bash
# أنشئ مستودع فاضي على github.com باسم areem_clinics ثم:
git remote add origin https://github.com/<اسمك>/areem_clinics.git
git push -u origin main
```

بعدها أي تحديث ينرفع على هذا المستودع، أمر `update` أو `watch` يسحبه ويشغّله.

## هيكل الملفات

```
lib/
  main.dart            نقطة البداية واللغة العربية
  theme.dart           الألوان
  data.dart            الأطباء، التواريخ، الأوقات
  state.dart           حالة التطبيق (المستخدم والمواعيد)
  widgets.dart         الأزرار والبطاقات المشتركة
  screens/             كل الشاشات
assets/doctors/        صور الأطباء بدون خلفية
scripts/dev.sh         أوامر التشغيل والتحديث
```
